# Exercícios de Lógica de Programação - JavaScript 🖥️

🚀 *Esta é minha primeira lista de exercícios do curso Fullstack Júnior do +prati!*

Este repositório contém a solução de 15 exercícios de lógica de programação utilizando JavaScript. Os exercícios abordam conceitos como **estruturas condicionais**, **loops** e **operações matemáticas**, com o objetivo de treinar e reforçar os conhecimentos em lógica computacional. 🎯


## Exercícios:

### 1. **Par ou Ímpar** 🤔
   - **Objetivo:** Verificar se um número fornecido é par ou ímpar.
   - **Descrição:** O programa lê um número inteiro e utiliza uma estrutura `if` para determinar se o número é par ou ímpar.

### 2. **Classificação de Idade** 👶👦👵
   - **Objetivo:** Classificar a idade de uma pessoa.
   - **Descrição:** O programa classifica a pessoa como **criança**, **adolescente**, **adulto** ou **idoso**, com base na idade fornecida, utilizando a estrutura `if-else`.

### 3. **Classificação de Notas** 📚
   - **Objetivo:** Classificar a nota de um aluno.
   - **Descrição:** O programa recebe uma nota de 0 a 10 e classifica como "Aprovado", "Recuperação" ou "Reprovado" utilizando `if-else if`.

### 4. **Menu Interativo** 📝
   - **Objetivo:** Criar um menu interativo para o usuário.
   - **Descrição:** O programa apresenta um menu com 3 opções e utiliza `switch-case` para executar a ação escolhida pelo usuário.

### 5. **Índice de Massa Corporal (IMC)** ⚖️
   - **Objetivo:** Calcular o IMC e classificar a categoria de peso.
   - **Descrição:** O programa calcula o IMC e classifica como **baixo peso**, **peso normal**, **sobrepeso** ou **obesidade**, utilizando a estrutura `if-else`.

### 6. **Triângulo** 🔺
   - **Objetivo:** Verificar se três lados formam um triângulo e identificar seu tipo.
   - **Descrição:** O programa verifica se os três valores fornecidos formam um triângulo e, se sim, identifica se ele é **isósceles**, **escaleno** ou **equilátero**.

### 7. **Cálculo da Compra de Maçãs** 🍏
   - **Objetivo:** Calcular o valor total de maçãs compradas.
   - **Descrição:** O programa calcula o preço total das maçãs compradas, aplicando diferentes preços dependendo da quantidade adquirida.

### 8. **Ordem Crescente** 🔢
   - **Objetivo:** Organizar dois números em ordem crescente.
   - **Descrição:** O programa lê dois números diferentes e os imprime em ordem crescente utilizando estrutura `if`.

### 9. **Contagem Regressiva** ⏰
   - **Objetivo:** Exibir uma contagem regressiva.
   - **Descrição:** O programa exibe os números de 10 até 1, utilizando um loop `for`.

### 10. **Repetir um Número 10 Vezes** 🔁
   - **Objetivo:** Exibir um número na tela 10 vezes.
   - **Descrição:** O programa lê um número inteiro e o exibe 10 vezes utilizando um loop `for`.

### 11. **Soma de 5 Números** ➕
   - **Objetivo:** Somar 5 números fornecidos pelo usuário.
   - **Descrição:** O programa solicita 5 números e soma os valores fornecidos utilizando um loop `for`.

### 12. **Tabuada de um Número** 🔢
   - **Objetivo:** Exibir a tabuada de um número.
   - **Descrição:** O programa recebe um número e exibe sua tabuada de 1 até 10 utilizando um loop `for`.

### 13. **Média de Números** 📊
   - **Objetivo:** Calcular a média de números fornecidos até o usuário digitar 0.
   - **Descrição:** O programa lê números decimais e calcula a média aritmética, parando quando o usuário digita 0.

### 14. **Cálculo do Fatorial** 🎲
   - **Objetivo:** Calcular o fatorial de um número.
   - **Descrição:** O programa calcula o fatorial de um número inteiro positivo fornecido pelo usuário.

### 15. **Sequência de Fibonacci** 🔢✨
   - **Objetivo:** Gerar a sequência de Fibonacci.
   - **Descrição:** O programa exibe os 10 primeiros números da sequência de Fibonacci.
